## Findings
- **23-tool roster confirmed** (17 memory_* + 4 source_* + agent_context + stage_lookup);
  the 21→23 delta is memory_retire + memory_restore (fills #62).
- **The file is a size-fit/resilience layer, not a semantics layer.** Every bounded
  response is fitted against `RESULT_MAX_CHARS` (40 000) by serializing the actual
  envelope and measuring, not by count caps; `ok()` is a whole-payload-omission net that
  never emits unparseable JSON. `stage_lookup` has a 3-tier omitted-rule recovery ladder
  (outline → ids → count-only, with `-partial` variants).
- **Auto-prewarm**: one-shot per process, snapshot-before-mutation, consumed-on-success /
  discarded-on-error; the stage-recognition cue is built incrementally against its own
  line budget (fix for whole-line-drop).
- **Model-tag "one chain"**: default resolved from `opts.modelTag ?? MONET_MODEL_TAG`,
  blank treated as absent, set once at registration, read at call time on the write path.
- **Server-bound source auth** (frozen context, never a tool arg) + graceful-shutdown
  machinery (in-flight quiesce 10 s + referenced-timer barrier 30 s + signal exit codes).

## Issues
