## Findings
- **RE-20 (perf, by design)** — every API request copies the entire store;
  no server-side caching/ETag. 75 MB → ~0.4–0.5 s per request regardless of
  response size; scales linearly with store size.
- **RE-21 (metric semantics)** — graphDensity = liveEdges/concepts includes
  possible_duplicate_of edges (184/5751 ≈ 3.2% on the E2E store); density is
  slightly inflated by dedup noise.
- **RE-22 (security posture, positive)** — local-only, Host-allowlisted,
  read-only (no write endpoints), no CORS, no auth needed; safe on shared
  workstations; no remote-monitoring path by design.
