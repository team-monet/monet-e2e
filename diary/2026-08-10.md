## Finding 1 — test05 re-run bug (GR-06 re-confirmed)
Fixed-circle-name tests accumulate state across runs, and **top-N search assertions break on

→ Applied GR-06 (fresh circle per run) to test05. A debug probe (`probe_c.py`) confirmed the

## Finding 2 — dedup works under concurrency (scenario 9 deepened)
4 server processes × 5 near-identical template stores (20 total, parallel) → **all merged into a
single concept** (unique=1, wall 2.2s, 0 lock errors). No race when multiple writers attach to
the same concept concurrently; dedup is safe across writers.

## Finding 3 — dedup threshold is aggressive (product observation)
Template-similar sentences differing only by noun (e.g. "a X crossed Y at dawn") still merge —
20 semi-distinct sentences collapsed to 5 concepts (1 per writer). Truly distinct sentence
STRUCTURE is required to stay separate (20 hand-written sentences → 20 unique concepts).
The actual dedup threshold is quite high — from a user perspective "similar things merge"
may feel too aggressive. Product review candidate.

## Finding 4 — dedup growth pattern (scenario 10)

- observationCount grows 1:1 with stores; body accumulates every observation
- DB layer: `observation_segments` == observations (1:1); `observation_tokens` accumulate
  per observation (5 obs → 45 tokens)
- Clearly distinct content stays in a separate concept (control passes)

## Finding 5 — needsSynthesis is eager (product observation)
`needsSynthesis=True` appears after just 2 observations attach to one concept —
there is no debounce/threshold. The product contract (memory_fetch doc) already
tells agents to pull every observation page and call memory_synthesize when the
flag is set, so this is consistent, but it means every multi-observation concept
is permanently flagged until an agent explicitly synthesizes.

## Finding 6 — synthesize is cheap and idempotent-ish
`synthesize` ack: `{version: 9, dirty: false, message: "synthesis stored"}`.
`version` = revision counter (10 stores → 9; created + 8 attaches? observed 9
for 10 obs — exact semantics need source check). Body is replaced atomically;
observations are preserved (retrievable with observations:true).

# 2026-08-10 — Run 5 (reverse-engineering): dedup similarity threshold LOCATED

## What was done
Source reverse-engineering run on `@team-monet/monet` v1.5.2
(`dist/index.js` + `dist/cli.js`, both minified esbuild bundles; core is duplicated
in both files). Priority-1 question from run 3 (Finding 3) is now answered:
**where the aggressive dedup threshold is defined.**

## Findings
1. **Thresholds are per-model hardcoded constants** in the config map `pU`
   (`XH` in cli.js):
   - `Xenova/bge-m3:cls:q8` (current fresh-store default pin `uU`):
     `tauAttach: 0.70`, `tauAmbiguous: 0.50`, `edgeSimMin: 0.60`, `nativeScoreFloor: 0.40`
   - `Xenova/bge-small-en-v1.5`: .78 / .50 / .70 / floor .35
   - `Xenova/all-MiniLM-L6-v2` and `Xenova/bge-m3` (mean): .72 / .50 (default `Sd`)
   - `Xenova/paraphrase-multilingual-MiniLM-L12-v2`: .70 / .50
   - hashing provider: .55 / .40; fallbacks .55 / .40 in `applyEmbedderDerivedThresholds`
2. **Decision function `V1`** (store path): attach happens only when
   `obsScore >= tauAttach` AND `centroidScore >= tauAmbiguous`; below tauAttach but
   >= tauAmbiguous → ambiguous fork (correction still attaches); below → `created`
   unless centroidTop >= tauAttach (blur-duplicate). Full table in
   `reverse-engineering/dedup-resolution.md`.
3. **No runtime override in the shipped binary**: store constructor accepts
   `tauAttach/tauAmbiguous/edgeSimMin`, but the CLI `start` path passes only
   scopeContext/defaultCircle/gateSidecarPath; no `MONET_TAU*` env var, no CLI flag.
   → Thresholds are effectively compile-time constants.
4. **Scoring pipeline documented**: `resolutionCandidates` (SQL filter) →
   `rankByCentroid` (cosine vs concept centroid, top `wi`=6) → `nominateByObservation`
   via `oT` (per-concept best observation/segment cosine; lexical-arm rank boost
   `j1(score,p)=score*(1+p)` with idf `z1=max(0,log(n/(1+df)))`). Lexical arm changes
   WHICH concept is nominated, but V1 compares raw cosine.
5. **E2E consistency**: template sentences differing by one noun exceed bge-m3 0.70 →
   attach (observed 20→5). Hand-written distinct sentences < 0.70 → new (observed 20→20).
